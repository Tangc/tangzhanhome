# 我的 OpenCode 应该用哪个模型？(最后有羊毛)

## 什么是 OpenCode？
开源，免费，美观，优雅，不绑定模型，全平台，全形态，社区繁荣
正热门的顶尖 CodeAgent，也是通用 Agent。
简单理解，不止是 ClaudeCode 的 “平替”，是“顶替”。
官网地址 opencode.ai ，官网文档全英文，不想啃的话可以看这个中文站
opencodecn.com 有全中文文档和最佳实践。

## 选择什么模型？
三个阶段
- 阶段1，试试水，没用过CodeAgent的。
  - 用 OpenCode 的免费模型就好。有 GLM4.7、MiniMax2.1、BigPickle、Grok Code Fast 1 四种。推荐用 GLM4.7 和 MiniMax，因为都是国产模型，方便后续付费使用，能力够用，性价比高。
  - 因为 OpenCode 今日的持续火爆，免费模型的限流情况越来越严重。
- 阶段2，免费额度不足，要经常用了。
  - 国产模型包月优先，性价比最高，首月有优惠的，先订阅用一个月再说。
  - 推荐(不分先后)
    - 【包月】智谱 CodingPlan 首月20元，次月40元。在免费阶段就用过 GLM4.7 的，可以顺畅切换。并且新用户还能免费用 GLM4.6，不妨一试。 CodingPlan链接，链接：https://www.bigmodel.cn/glm-coding?ic=ENXUDAKUIN ，使用方法 /connect 选择 Zhipu AI Coding Plan 输入 API Key 后使用。
    - 【包月】豆包 CodingPlan 字节就是卷，首月8.9元 次月40，而且也可以用到 GLM4.7 链接：https://volcengine.com/L/wwt7V_Dv1HI/  邀请码：RWYPVFMZ ，使用方法 按官方文档修改配置文件 https://www.volcengine.com/docs/82379/1928262?lang=zh#5eed7f50，选择 ark-code-lastest 模型使用
    - 【API计费】DeepSeek V3.2，deepseek效果好价格低，除了不包月什么都好，在官方api平台充值即可使用，地址 https://platform.deepseek.com/ ，使用方法 /connect 选择 deepseek，输入apikey后获得模型使用
    - 【套餐】Kimi for Coding，如果你刚好是 Kimi 的会员，那么会员里包含了编程权益，可以直接使用，在会员页的权益列表里，点击 Kimi for Coding 获得 token 。不是会员不建议买，kimi 的 API 用着很贵。使用方法，/connect 选择 kimi for coding ，输入 apikey 后获得模型。
    - 【API计费】硅基流动，大模型聚合服务商，想经常换着模型用的可以在硅基充钱。链接：cloud.siliconflow.cn ，使用方法，参考官方的cc文档 https://docs.siliconflow.cn/cn/usercases/use-siliconcloud-in-ClaudeCode，手动修改配置文件 ~/.config/opencode/opencode.jsonc 配置 provider 和 model，设置 baseURL 和 model 使用。
    - 【包月】阿里云百炼CodingPlan，首月10元，次月40元。链接：https://bailian.console.aliyun.com/cn-beijing/?tab=globalset#/efm/coding_plan 。 使用方法 /connect 选择 Alibaba(China)，输入 apikey 获得模型列表。 百炼本身会提供一点的免费额度，可以先试后用。注意 CodingPlan 只能使用 qwen3-coder-plus 模型
- 阶段3，需要更高能力上限的模型或者富哥们
  - 御三家订阅 ChatGPT、Gemini 和 Claude，但其中不推荐 Claude (反中，封号严重)。订阅方法各显神通。
  - 选择聚合平台。推荐 Zen 和 OpenRouter。zen是OpenCode的开发团队自己经营的聚合平台，充值后按 credit 扣费，初期费用应该有一些优惠，可以尝试。 OpenRouter 是老牌聚合商模型齐全，用着放心。
OpenCode不和模型绑定，用起来很自由，甚至可以自己部署模型使用、用公司部署的模型等等都支持，总之，丰俭由人。

## 羊毛彩蛋1
Google随Gemini 3 Pro推出了自己的编程IDE，Antigravity，现在在测试阶段，有一些免费额度是可以使用的，如果你刚好订阅了 Gemini，额度会更丰富。
推荐两个工具 
- 1、安装 https://github.com/lbjlaq/Antigravity-Manager ，可以查看到自己通过 Antigravity 可使用的额度情况。它也是个代理，可以转换模型成各种格式去使用，可自行摸索，注意账号安全(用太狠被封的风险)。
- 2、安装 OpenCode 的 Antigravity 插件 (如果安了 oh-my-opencode 插件的话不用单独安装，里面带了)，可以授权 Antigravity 的 Gemini 额度给 OpenCode 用。 Gemini 3 Pro 做前端页面效果不错，可以和你的其他订阅配合着用。这个羊毛可以用起来。

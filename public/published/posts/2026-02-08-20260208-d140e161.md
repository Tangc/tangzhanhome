## 1. Claude Code 的新功能：/insights
最近 Claude Code 更新了一个非常有用的命令：`/insights`。
它能深入分析你的历史对话记录，生成一份详细的洞察报告。这份报告不仅会指出你用得好的地方，还会给出具体的改进建议，绝对是提升 Claude Code 使用熟练度的神器。

**使用方法：**
在对话框输入 `/insight` 即可。生成的报告通常位于 `./claude/usage-data/report.html`。

**前置条件：**
你需要将 Claude Code 升级到最新版本。升级方式如下（任选其一）：
```bash
# 方式一：官方脚本
curl -fsSL https://claude.ai/install.sh | bash

# 方式二：自带更新命令
claude update

# 方式三：Homebrew
brew upgrade claude-code
```

## 2. 我为什么主力切换到 OpenCode？
虽然 Claude Code 不错，但我最近已经全面切换到 **OpenCode** 了。主要原因有五点：
*   **完全开源**：代码透明可追溯，不仅所有功能可解释，我甚至能亲自参与迭代。
*   **免费使用**：工具本身免费，而且支持多种模型（最近甚至可以白嫖 Kimi K2.5）。
*   **模型自由**：原生支持多模型切换，不再绑定 Claude，彻底摆脱被单一模型“卡脖子”的气！
*   **社区繁荣**：配合 `oh-my-opencode`，能获得开箱即用的 AI 编程最佳实践，体验极佳。
*   **生态兼容**：完美支持 Skill 特性，且兼容 Claude Code 和 Codex 的配置路径，迁移成本几乎为零。

## 3. OpenCode 版 Insights Skill（已开源）
参考 Claude Code 的 `/insights` 功能，我利用 OpenCode 的 Skill 机制，开发了一款**项目级洞察技能**。


## 4. 进阶玩法与未来展望
目前的 Insights 功能还是单次触发的，需要手动执行。我设想的终极解决方案应该是自动化的闭环：
1.  **定时执行**：比如设定为每周自动运行一次，生成周报。
2.  **自动迭代**：让 OpenCode 自己读取报告，并根据建议自我优化配置或习惯。
3.  **数据导向**：设定“北极星指标”（如会话中断次数、输入输出比等），通过监控这些指标来验证迭代是否有效。这才是体现个性化和技术水平的地方。

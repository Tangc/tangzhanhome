## 2、Cowork，阶跃 AI 和 Clawdbot

Anthropic 推出了桌面 AI 助理 **Cowork**，宣传口径是 **Claude Code** 是编程 Agent。虽然能力具备通用性，但黑乎乎的命令行对非技术人员还是有壁垒，所以他们自己做了 Cowork 这样有 GUI 的 Agent 来解决非编程场景的问题，比如办公、日常事务、个人助理等等。

我的观点是，**Agent + Skill** 就是最好的轻量 AI 生产力解决方案，真的还需要一个 GUI 外壳吗？

以 **OpenCode** 来说，通过 Web 和 Desktop App 两种交互形态，已经把使用门槛打到非常低了。GUI 可能会引来更多尝鲜者，但 TUI (Text User Interface) 更能筛选出真正愿意投入其中的用户。所以我觉得 Anthropic 应该从 Claude Code 出发，而不是做一个新产品。

趁着 Cowork 的热度，开源的、国内的各种桌面 AI 助理产品也出来了，比如开源的 **Eigent**（国内开发者做了挺长时间的产品）。

还有新出的 **阶跃 AI 桌面助理** (阶跃星辰)，有一个全局记忆的功能，可以记录你的桌面，一天下来分析你的使用情况，有点像 **Looki AI** 那样回看总结，挺有意思的。

以及这两天最热门的 **Clawdbot**，它和其他产品最大的区别是把 AI 从浏览器窗口、从电脑桌面提取出来了，放到了 IM 里面，更贴近你的地方。不管用电脑还是用手机，都可以随时和它联系，让它给你处理各种事情。

我这两天会安装体验一下，后续分享感受。

## 3、怎么让自己的 Skill 被安装

说 MCP 和 Skill 是“开发者比使用者还多”的两种技术。比如 **skillsmp.com** 上从 GitHub 抓到的 Skill 已经有 9w 多个了。虽然 Skill 是基于文本文件和文件夹的，分发很方便，但传输压缩文件、解压再移动总是个麻烦事。

所以 **Vercel** 出手了。Vercel 的 **skills.sh** 提供了一种 `npx` 的安装方式，可以一行命令把你从 GitHub 上看到的、符合 Repo 格式的 Skill 安装到你电脑上（支持所有主流的 Agent 目录），非常方便。

我做了一个例子，用来简化 JS 代码的（源自 Anthropic 官方的代码简化 Agent）。在安装了 Node.js 的电脑上，用这个命令就可以安装：

```shell
npx skills add https://github.com/Tangc/tangzhan-skills --skill code-simplifier
```

你不妨尝试一下，体验下效果。`add` 后面是 GitHub 的 Repo 地址，`--skill` 后面是 Skill 的名字。Skill 的存放规则是在 Repo 根目录下的 `skills` 目录下的 Skill 对应目录，比如我的 Repo 里就是 `skills/code-simplifier`。

## ❌ 实际情况

不是真正的"免费"，是翻译错误。

OpenClaw 是一个开源的 AI Agent 框架，它本身不提供模型算力。你需要自己接入模型 API，而这些 API 都要钱。
对比 OpenCode 可以免费用模型是因为 Zen 是它自营的模型聚合服务，才有承载免费的地方。

### 各渠道实际收费

| 渠道 | 收费情况 |
|------|----------|
| Moonshot 官方 API | 按 token 收费（$0.60/M input, $3/M output）|
| OpenRouter | 按 token 收费（$0.50/M input, $2.80/M output）|
| Synthetic | 订阅制 $20/月起，不是免费 |
| NVIDIA NIMs | ✅ 真正免费（有 rate limit）|

## 🤔 那"免费"是什么意思？

经过核实，for free "免费开箱即用"的真实含义是：
OpenClaw 帮你配好了：不用自己折腾 endpoint、模型参数，开箱即用
NVIDIA 提供免费体验 API：去 build.nvidia.com 登录可获得免费 API Key
Synthetic 是订阅制："不按 token 收费" ≠ "免费"，$20/月起步
## ✅ 真想白嫖怎么办？

唯一零成本的路径：
去 NVIDIA NIMs 平台注册账号
搜索 Kimi K2.5，登录后自动获得 API Key
把 Key 配到 OpenClaw
注意：NVIDIA 的免费 API 有请求限制，适合体验和轻度使用，不适合生产环境。
